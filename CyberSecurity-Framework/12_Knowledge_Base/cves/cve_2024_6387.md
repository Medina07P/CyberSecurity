# CVE-2024-6387 - OpenSSH Race Condition (regreSSHion)

## Información

| Campo      | Valor           |
|------------|-----------------|
| CVE ID     | CVE-2024-6387   |
| Fecha      | 2024-07-09      |
| Severidad  | Crítico         |
| CVSS       | 8.1             |

## Descripción
Vulnerabilidad de race condition en OpenSSH que permite ejecución remota de código.

## Sistemas Afectados
- OpenSSH 8.5p1 - 9.8p1
- Debian, Ubuntu, Fedora, CentOS

## Prueba de Concepto

```bash
# Verificar versión
ssh -V

# Testear vulnerabilidad
ssh -o "KexAlgorithms=diffie-hellman-group14-sha256" -v <target>
```

## Mitigación
- Actualizar OpenSSH a versión 9.8p2
- Habilitar firewall
- Monitorear logs
