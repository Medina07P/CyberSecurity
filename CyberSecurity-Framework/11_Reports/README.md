# 📊 11_Reports - Informes de Auditoría

Este directorio contiene todos los informes generados durante la auditoría.

## 📁 Estructura

| Directorio | Descripción |
|-----------|-------------|
| `executive/` | Informe ejecutivo (resumen para directivos) |
| `technical/` | Informe técnico detallado |
| `templates/` | Plantillas para informes |
| `final_report/` | Informe final completo |
| `evidence/` | Evidencias empaquetadas |

## 🚀 Uso Rápido

```bash
# Generar reporte ejecutivo
./report_generator.sh --executive

# Generar reporte técnico
./report_generator.sh --technical

# Generar reporte completo
./report_generator.sh --full

# Generar PDF
./report_generator.sh --pdf
