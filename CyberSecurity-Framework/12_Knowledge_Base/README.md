# 📚 12_Knowledge_Base - Base de Conocimiento

Base de conocimiento para consulta rápida durante auditorías.

## 📁 Estructura

| Directorio        | Descripción                    |
|-------------------|--------------------------------|
| `cheatsheets/`    | Hojas de referencia rápida     |
| `methodologies/`  | Metodologías de auditoría      |
| `cves/`           | Documentación de CVEs          |
| `notes/`          | Notas y plantillas             |
| `procedures/`     | Procedimientos estándar        |

## 🚀 Uso Rápido

```bash
# Buscar en la base de conocimiento
./search_kb.sh "SQL injection"

# Ver un cheatsheet
cat cheatsheets/nmap_cheatsheet.md

# Buscar un CVE
grep -r "CVE-2024" cves/
```

## 📋 Flujo de Trabajo

```
1. Consultar cheatsheets  → Comandos rápidos
2. Revisar metodologías   → Enfoque de auditoría
3. Documentar CVEs        → Exploits conocidos
4. Tomar notas            → Hallazgos y aprendizajes
5. Seguir procedimientos  → Estándares de calidad
```
