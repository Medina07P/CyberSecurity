# CVE-2023-44487 - HTTP/2 Rapid Reset Attack

## Información

| Campo      | Valor            |
|------------|------------------|
| CVE ID     | CVE-2023-44487   |
| Fecha      | 2023-10-10       |
| Severidad  | Alto             |
| CVSS       | 7.5              |

## Descripción
Ataque de denegación de servicio en HTTP/2 usando frames RST_STREAM.

## Sistemas Afectados
- Servidores web con HTTP/2
- nginx, Apache, Envoy, Tomcat

## Mitigación
- Deshabilitar HTTP/2 temporalmente
- Actualizar servidores web
- Configurar límites de conexiones
