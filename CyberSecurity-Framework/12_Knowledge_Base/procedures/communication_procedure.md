# PROCEDIMIENTO DE COMUNICACIÓN

## 1. Canales

| Tipo       | Canal    | Uso                      |
|------------|----------|--------------------------|
| Urgente    | Teléfono | Hallazgos críticos       |
| Prioridad  | Correo   | Actualizaciones diarias  |
| Estándar   | Reporte  | Entregas formales        |

## 2. Frecuencia de Comunicación
- **Diaria:** Actualización de progreso
- **Crítica:** Inmediata para hallazgos críticos
- **Semanal:** Revisión de hallazgos
- **Final:** Entrega de reporte

## 3. Plantillas de Correo

### Actualización Diaria
```
Asunto: Actualización Auditoría - [FECHA]

Estimado [CONTACTO],

Progreso del día:
- Fase: [FASE]
- Avance: [%]
- Hallazgos: [NÚMERO]

Próximos pasos:
- [PASO 1]
- [PASO 2]
```

### Hallazgo Crítico
```
Asunto: [URGENTE] Hallazgo Crítico Encontrado

Estimado [CONTACTO],

Se ha identificado un hallazgo crítico:
- Descripción: [DESCRIPCIÓN]
- Impacto: [IMPACTO]
- Recomendación: [RECOMENDACIÓN]

Se recomienda acción inmediata.
```
