# PROCEDIMIENTO DE RESPUESTA A INCIDENTES

## 1. Detección
- Identificar el incidente
- Documentar la evidencia inicial
- Determinar el alcance

## 2. Análisis
- Recopilar logs
- Analizar el impacto
- Identificar vectores de ataque

## 3. Contención
- Aislar sistemas afectados
- Bloquear tráfico malicioso
- Deshabilitar cuentas comprometidas

## 4. Erradicación
- Eliminar malware
- Desactivar backdoors
- Parchear vulnerabilidades

## 5. Recuperación
- Restaurar sistemas
- Cambiar credenciales
- Validar integridad

## 6. Lecciones Aprendidas
- Documentar el incidente
- Identificar mejoras
- Actualizar procedimientos
